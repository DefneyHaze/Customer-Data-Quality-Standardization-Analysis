# Customer Data Quality Dashboard

## Overview
This project presents a **Power BI dashboard** designed to evaluate the quality of customer contact data.  
It highlights the proportion of **valid, invalid, and missing entries** for both emails and phone numbers, and calculates an overall **Data Quality Score**.

---

## Features
- **Valid Emails & Phones**: Quick counts of clean records.
- **Data Quality Score**: Gauge chart showing overall data integrity.
- **Email Status Distribution**: Breakdown of valid vs missing emails.
- **Phone Status Distribution**: Breakdown of valid, invalid, and missing phone numbers.
